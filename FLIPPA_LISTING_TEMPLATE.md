### 🎮 Key Product Features & Gameplay Mechanics
1. **Hypnotic Physics Ricochet Loop**:
   - Player aims a high-powered launcher using mouse drag or touchscreen swipe with realistic multi-bounce trajectory raycasting.
   - Fire volleys of glowing neon orbs that cascade and ricochet against geometric nodes (Hexagon Cores, Crystal Diamonds, Reflector Prisms, Plasma Bombs, Laser Triggers, and Mega Titan Bosses).
   - Dynamic pentatonic chime synthesis: each rapid bounce scales up a musical harmonic ladder, providing supreme sensory satisfaction.
2. **Deep Roguelite Draft Upgrades (Relic System)**:
   - Every 3 waves cleared, players choose 1 of 3 randomized Synth Relics:
     - *Splitter Matrix*: 22% chance to clone mini-orbs on impact for massive cascades.
     - *Arc Discharge*: Orb strikes jump chain lightning arcs across adjacent targets.
     - *Quantum Piercer*: Orbs slice straight through nodes without deflecting.
     - *Plasma Nova*: Triggers a high-voltage shockwave every 8 bounces.
     - *Kinetic Stacker*: Permanently ramps up orb damage with every bounce.
3. **High-Retention Meta-Progression (Synth Lab)**:
   - "Synth Credits" collected during runs allow permanent base upgrades (Starting Orbs Battery, Plasma Core Damage, Critical Strike Frequency, EMP Baseline Barrier).
   - Encourages repeated play sessions and long-term user retention.
4. **Cross-Platform & Mobile Optimized**:
   - 100% responsive viewport scaling seamlessly to iOS Safari, Android Chrome, and Desktop browsers.
5. **Zero External Asset Dependencies**:
   - All sound effects (arpeggios, explosions, lasers, fanfare, synthwave bassline) are synthesized procedurally via the browser's native Web Audio API. Zero missing files or expired CDNs.
6. **Global REST API Leaderboard**:
   - Lightweight Express/Node.js backend with JSON persistence, recording high scores, wave milestones, and winning builds.
